Core Concepts at a Glance

Interactive cards showcasing key rules, syntax, and production examples.

Visual FX

CSS Filters

Applies graphical effects like blur, color shifts, brightness, and contrast directly to elements before rendering.

filter: blur(5px) grayscale(80%);
Responsiveness

Media Queries

Enables conditional CSS rules based on device properties such as viewport width, height, resolution, or orientation.

@media (max-width: 768px) { ... }
Layout

Responsive Design

The practice of crafting flexible layouts, fluid proportions, and flexible media that dynamically fit any viewport seamlessly.

display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
Type Systems

Fluid Typography

Scales text smoothly between minimum and maximum bounds proportional to the user viewport width using clamp functions.

font-size: clamp(1rem, 2.5vw, 2rem);
One-Dimensional Layout

CSS Flexbox

Distributes available space among items along a single axis (row or column) with robust alignment, wrapping, and distribution rules.

display: flex; justify-content: space-between; gap: 1rem;
Units

Relative Units

Dynamic sizing units like vw, vh, rem, and ch that decouple styling from rigid, non-accessible fixed pixels.

width: 90vw; padding: 2rem; max-width: 65ch;
