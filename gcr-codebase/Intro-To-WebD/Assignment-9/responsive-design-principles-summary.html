01

Fluid Layouts

Fluid layouts utilize relative proportions such as percentages, fractions (fr), and viewport units (vw, vh) rather than rigid pixel dimensions, allowing containers to scale continuously with the browser window.

CSS Example 
.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  width: 90vw;
  max-width: 1200px;
}
02

Flexible Media

Flexible media ensures embedded assets like imagery, video streams, and vector canvases automatically scale within their parent bounding boxes without overflowing or distorting aspect ratios.

CSS Example 
img, video, iframe {
  max-width: 100%;
  height: auto;
  display: block;
  object-fit: cover;
}
03

Breakpoints

Breakpoints are strategic viewport thresholds defined via CSS Media Queries where structural layout shifts, typography scales, or component reordering occur to optimize ergonomics for target screen dimensions.

CSS Example 
@media (min-width: 768px) {
  .sidebar {
    display: block;
    width: 260px;
  }
}
