JavaScript Assignment 7: DOM Manipulation Suite

Clean HTML5, CSS3, & Core ES6+ JavaScript | Tested across Node.js Console & Browser DOM

1. Dynamic Product List Manager

Add, edit, delete products using Event Delegation on parent <ul>, inline editing, and outside-click auto-save.

2. Live Character Counter

Tracks remaining characters (max 100). Turns yellow at 20 left, turns red at 0 and blocks typing using preventDefault().

3. Multi-Step Form with Next/Back

3-step wizard with validation (Name, Email, Password). Advances only on valid input, allows going back, and presents final summary card.

4. Theme Switcher via setAttribute

Switches between Light, Dark, and Blue themes strictly using setAttribute() to modify class and data-theme.

5. Image Gallery with Modal Preview

6-image responsive grid with popup modal. Outside clicks close modal, while event.stopPropagation() protects inner modal clicks.

6. Real-Time Table Filter

Reactively filters student table on input event. Case-insensitive search across Name, Branch, and CGPA with "No results found" fallback.

7. Mouse Path & Coordinates Logger

Exact 400×400 px interactive box. Tracks live clientX and clientY on mousemove. Double-clicking drops permanent red dots.

8. Custom Dropdown (No <select>)

Built with core JS without <select> tags. Uses Capturing Phase (useCapture: true) to handle closing when clicking outside.

9. Form Blocker with Live Errors

Stops submission via preventDefault() on invalid input. Shows inline errors that automatically disappear as the user corrects their input.
