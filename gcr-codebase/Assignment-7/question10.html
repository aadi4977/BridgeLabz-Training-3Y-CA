Responsive Navigation Bar Demonstration

This navigation bar is built using semantic HTML5 (header, nav, ul, li) and CSS Flexbox.

Key Features:

  • 5 horizontal navigation items with borders, padding, and rounded corners.
  • Smooth 0.3s transitions on hover for background and border colors.
  • The Home link is set as .active with a highlighted blue background.
  • Media query at max-width: 700px collapses the horizontal bar into a full-width vertical stack.
Resize your browser below 700px to test responsiveness
