Height & Width Practice Layout

Exploring sizing units (px, %, vh, em), min/max limits, and overflow properties

Box 1: px & em Units

  • Width: 270px
  • Min-Height: 19em
  • Max-Width: 300px
  • Overflow: hidden

This card relies on px for fixed width and em for height relative to font size. The overflow: hidden rule trims any content that spills beyond its boundaries.

Box 2: % & vh Units

  • Width: 30%
  • Min-Height: 40vh
  • Max-Width: 320px
  • Overflow: auto

This card scales with the browser width using 30% and has a height of at least 40vh.

Because overflow: auto is set, if the text exceeds the container height, a scrollbar appears automatically so the reader does not lose any information. Extra text here ensures the scroll behavior is active when resized.

Box 3: em & vh Units

  • Width: 18em
  • Min-Height: 30vh
  • Max-Width: 280px
  • Overflow: visible

This card uses em for width and viewport height (vh) for its minimum height. Default overflow: visible lets child elements stay visible even if they extend outside.
