CSS Transformations Showcase

Hover over each shape to trigger rotate(), scale(), translate(), and skew()

Rotate
Rotation
transform: rotate(25deg)

Pivots the box clockwise by 25 degrees on hover.

Scale
Scaling
transform: scale(1.22)

Magnifies the box dimensions uniformly by 22%.

Translate
Translation
transform: translateY(-22px)

Shifts the box vertically upwards by 22 pixels.

Skew
Skewing
transform: skewX(-16deg)

Distorts the angles along the X-axis by -16 degrees.
