Box-Sizing Comparison

Comparing content-box against border-box with identical width and padding

Identical Declared Values for Both Boxes:
width: 220px; • padding: 25px; • border: 8px solid;

content-box (Default)

220px Box
(Expanded)
Total Rendered Width: 286px Calculation:
220px (Content)
+ 50px (25px × 2 Padding)
+ 16px (8px × 2 Border)
= 286px total

border-box

220px Box
(Preserved)
Total Rendered Width: 220px Calculation:
Padding and border are absorbed inside the declared width.
Content width shrinks to 154px.
= 220px total

Why This Matters: In default content-box, any padding or border is added on top of the specified width, frequently causing unintended grid overflows. Setting box-sizing: border-box locks the rendered outer width to exactly 220px, making layouts predictable and responsive.
