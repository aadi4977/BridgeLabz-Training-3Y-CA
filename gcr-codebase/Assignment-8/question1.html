Demonstration of CSS Pseudo-Classes

Exploring :hover, :focus, :active, and :nth-child() aligned in a single Flexbox row

1. :hover

Hover Over Me

:hover triggers when the mouse pointer glides over an element. Here, the link inverts its text color and gains a blue fill.

2. :focus

:focus activates when an input field receives keyboard or mouse focus. Here, the border turns green with a subtle glow.

3. :active

:active represents the exact moment an element is being clicked down. The button sinks down 3px and deepens in color.

4. :nth-child()

  • Item 1 (Odd)
  • Item 2 (Even)
  • Item 3 (Special 3rd)
  • Item 4 (Even)

:nth-child() targets elements by index. Even items get a light blue tint while the 3rd child has a distinct red accent.
